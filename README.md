# ⚡ Fiches de Révision – Électricité (Sketchnotes)

Une collection de fiches de révision sur les bases de l'électricité, réalisées au format **sketchnote** : un mélange de texte synthétique, de schémas et de dessins pour faciliter la mémorisation et la compréhension visuelle.

## 🎯 Objectif

Ces fiches rassemblent les notions fondamentales d'électricité utiles pour réviser rapidement avant un examen, une habilitation, ou tout simplement pour consolider ses bases. Chaque fiche traite d'un concept en une seule image, pensée pour être lue et comprise en quelques minutes.

## 🖊️ Pourquoi le format sketchnote ?

Le sketchnote combine texte, hiérarchie visuelle et petits dessins pour :
- Rendre l'information plus facile à mémoriser qu'un texte classique
- Permettre une lecture rapide, d'un coup d'œil
- Créer des repères visuels qui aident à se souvenir du contenu même après un premier passage

## 📖 Comment utiliser ces fiches

1. Parcours les fiches par thème selon ce que tu révises
2. Imprime-les ou garde-les sur un second écran pendant tes révisions
3. Reviens régulièrement dessus pour ancrer les notions dans la durée
